# iMart App

Mobile client of **iMart**, a market management system. Focus on stock control with barcode scanning.

## Stack

- React Native + Expo
- React Navigation (stack)
- Axios for API calls
- `expo-camera` for barcode reading

## Screens

`Login`, `Initial`, `StorageConsult`, `StorageMovement`, `StorageRegister`

## Run

```bash
npm install
npx expo start
```

The web client lives in [imart-web](https://github.com/gabrielfel1x/imart-web).
